# Public documentation and confidential invention records

The existing public source remains under its existing license. This notice does not withdraw licenses, erase Git history or convert published code into a trade secret. An ignore rule is only an accidental-staging guard.

Publish cleared capability names, honest readiness, synthetic non-proprietary test records and the public package's reproducible validation. Keep unpublished invention disclosures, draft claims, detailed proprietary methods, private calibration, pricing, provider configuration, identities and customer data outside this repository and its Actions artifacts.

Maintain confidential counsel-review records separately with dated authorship, exact-build evidence, claim-to-description support, disclosure dates, drawings and ownership documentation. Patents require an enabling disclosure; a patent-ready technical specification and permanent secrecy of the same claimed invention are different protection choices.

Patentability, US software eligibility, prior disclosures, existing license terms and Nepal's local procedure need professional review. No patent application, registration or patent-pending status is represented by this documentation.

References: [USPTO disclosure requirements](https://www.uspto.gov/web/offices/pac/mpep/s608.html), [USPTO international disclosure considerations](https://www.uspto.gov/patents/basics/international-protection/filing-patents-abroad), [Nepal Department of Industry patent law](https://doind.gov.np/uploads/notices/Notices-20231012183159211.pdf).
